LingoBot — Robot đồng hành học tiếng Anh

ESP32-S3 + màn cảm ứng 4 inch, chatbot giọng nói xiaozhi, nhạc thẻ nhớ, vỏ in 3D

LingoBot là một “bạn cùng lớp” giúp luyện nói tiếng Anh. Máy nghe, hiểu và nói được cả tiếng Việt lẫn tiếng Anh. Nó dạy từ vựng, sửa lỗi phát âm, kể chuyện tiếng Anh và phát nhạc từ thẻ nhớ. Bản thân thiết bị chỉ thu âm, hiển thị và phát loa. Nhận dạng giọng nói, mô hình ngôn ngữ (Qwen) và đọc giọng nói đều chạy trên máy chủ xiaozhi.me, nên phần cứng rất rẻ.

Tính năng

  • Trò chuyện bằng giọng nói: chạm nút NÓI hoặc gọi “Hi ESP”. Mặc định nói tiếng Việt, chuyển sang tiếng Anh khi dạy hoặc luyện nói.
  • 3 chế độ học: Kể chuyện tiếng Anh (thư viện 20 truyện), Học từ vựng, Nghe nhạc tiếng Anh.
  • Nhạc từ thẻ nhớ: nói “phát bài Jingle Bells” hoặc “mở một bài bất kỳ”. File MP3 phát ngay trên máy.
  • Giao diện cảm ứng: khuôn mặt biểu cảm, các nút Nói / Âm lượng / Home / Pause / Reset / Đổi WiFi.

Nạp firmware

Không cần cài ESP-IDF trên máy tính, GitHub Actions sẽ build giúp bạn.

  1. Fork github.com/78/xiaozhi-esp32 về tài khoản GitHub của bạn.
  2. Giải nén LingoBot_firmware.zip. Chọn thư mục ban_doc_hop_radio (màn dọc) hoặc ban_ngang_robot (màn ngang). Tải toàn bộ file trong đó vào main/boards/bread-compact-wifi-lcd/ bằng Add file → Upload files.
  3. Vào tab Actions và chờ build xong (khoảng 8 phút). Tải mục Artifacts về, giải nén để lấy merged-binary.bin.
  4. Mở ESP Tool trên Chrome hoặc Edge, bấm Connect rồi nạp file ở địa chỉ 0x0.
  5. Lần đầu bật máy: chạm vào tâm 3 dấu + đỏ để hiệu chỉnh cảm ứng. Kết nối WiFi Xiaozhi-xxxx, mở 192.168.4.1, rồi nhập mã 6 số trên xiaozhi.me.

Cấu hình AI trên xiaozhi.me

  • Role: tên LingoBot, ngôn ngữ Vietnamese, giọng nữ.
  • Model: Qwen 3.6 (Fast), bật Memory. Cần xác minh GitHub để dùng model này.
  • Knowledge Base: tải file ThuVien_LingoBot.txt lên rồi tích chọn trong Extensions. Nếu dùng nhạc thẻ nhớ thì bỏ tích Music.
Mẫu mô tả vai trò: “Bạn là LingoBot, robot đồng hành khám phá ngôn ngữ, là bạn cùng lớp giúp mình học tiếng Anh. Mặc định nói tiếng Việt, chỉ dùng tiếng Anh khi dạy. Mỗi lần dạy tối đa 5 từ, có nghĩa và câu ví dụ. Khi mình nói sai thì khen trước rồi sửa. Muốn phát nhạc thì gọi self.music.play, không nêu tên bài thì dùng name là random. Nếu nghe không rõ thì nhờ mình nói lại.”

Vỏ in 3D

In bằng Orca Slicer, nhựa PETG, lớp 0,2 mm, độ đặc 15%. Hộp radio thì úp mặt trước xuống bàn, không cần support. Robot thì in từng mảnh (mảnh lớn nhất 109×109×195 mm), ghép bằng chốt sợi nhựa 1,75 mm và keo, tốn khoảng 1,5 kg nhựa.

Loại nhựa chọn trong slicer phải trùng với loại nhựa khai báo trên máy in, nếu không máy sẽ từ chối in. Với Creality Hi, chọn host CrealityPrint để gửi file qua mạng.

Hỏi đáp

Màn hình ngược màu hoặc lộn ngược?

Nếu ngược màu, đổi qua lại giữa CONFIG_LCD_ST7796_320X480 và ..._NO_IPS trong config.json. Nếu bản ngang bị lộn ngược, đặt LINGOBOT_FLIP_180 thành 1 trong config.h.

Báo “No SD card”?

Thẻ phải định dạng FAT32 và hàng J4 phải được hàn header. Kiểm tra lại các chân SD_CS 10 / MOSI 11 / SCK 9 / MISO 8.

Phát nhạc báo không tìm thấy bài?

Tên file .mp3 chính là tên bài. Sau khi chép thêm bài vào thẻ, bấm RESET để máy quét lại.

Muốn đổi WiFi?

Chạm nút “Đổi WiFi” ở màn hình chính, kết nối mạng Xiaozhi-xxxx, mở 192.168.4.1 rồi chọn mạng mới (chỉ hỗ trợ 2.4 GHz).
